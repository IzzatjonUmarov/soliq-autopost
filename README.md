# Автопостинг для @Soliqmobilxizmati

Бот сделан по схеме [uz-business-news](https://github.com/IzzatjonUmarov/uz-business-news): работает в GitHub Actions бесплатно, круглосуточно и без компьютера.

**Бот ничего не сочиняет.** Все тексты взяты из источников как есть, а в каждом посте стоит ссылка на первоисточник. ИИ и ключ Anthropic не нужны.

## Что делает бот

| Время (Ташкент) | Пост | Откуда текст |
|---|---|---|
| 07:00 | **Цитата дня** о деньгах и финансах | Страницы Викицитатника (ru.wikiquote.org): «Деньги», «Богатство», «Долг», «Труд», «Налог» и другие. Текст и автор берутся как на странице |
| 18:00 | **Новость дня**: кешбэк, переводы, карты, вклады, тарифы, налоги | 17 банков, Налоговый комитет (gov.uz), Kun.uz, Газета.uz, Spot.uz. Заголовок и описание берутся со страницы новости |

- **Два языка в одном посте:** сверху русский, ниже узбекский. Узбекскую версию бот сначала ищет на сайте источника. Если её там нет, текст переводится бесплатным переводчиком (Google или MyMemory), как в uz-business-news. Узбекский пишется латиницей в новой редакции алфавита по закону ЗРУ-1184 от 21.10.2026: ş, ç, ö, ğ.
- **Картинка:** берётся фото новости, а если его нет, бот делает карточку с заголовком. У цитаты карточка с текстом цитаты. На любой картинке есть плашка @Soliqmobilxizmati и бледный диагональный повтор.
- **Отбор новости:** по ключевым словам. «Кешбэк», «без комиссии», «перевод», «НДС», Click, Payme, Uzum весят больше, а «карта», «вклад», «кредит», «тариф», «акция» меньше. Поздравления, вакансии, спорт и семинары не берутся. Новость должна быть не старше 3 дней и раньше не выходить.
- **Отбор цитаты:** только с конкретным автором. Записи с пометкой «приписывается» или «сомнительно», пословицы и «Автор неизвестен» пропускаются. Цитаты не повторяются.
- **Нет подходящего — нет поста.** Если за 3 дня не нашлось новой новости по теме, вечерний пост в этот день не выходит.
- **Без дублей и залпов:** после каждого поста состояние сразу сохраняется. Если бот опоздал больше чем на 3 часа, пост этого слота пропускается.

## Настройка (один раз)

1. **Бот Telegram.** Отправьте @BotFather команду `/newbot` и получите токен. Добавьте бота в канал **администратором** с правом «Публикация сообщений».
2. **Секрет.** Откройте Settings → Secrets and variables → Actions → **Secrets** и создайте `TELEGRAM_BOT_TOKEN`, вставив туда токен бота.
3. **Проверка.** Откройте Actions → **Проверка и тестовый пост** → Run workflow → `check`. Бот покажет, какие источники работают, сколько цитат нашлось и есть ли у него права в канале.
4. **Пробный пост.** Тот же запуск с `morning` или `evening` и отмеченным `dry_run`. Текст будет в логе, а картинка в артефакте `preview` внизу страницы запуска. В канал ничего не уйдёт.
5. **Запуск.** Откройте Actions → **Автопостинг** → Run workflow. Дальше бот работает сам.

## Управление

| Действие | Где |
|---|---|
| Что делает бот сейчас | Actions → последний запуск «Автопостинг» → шаг «Работа бота» |
| Пауза | Actions → Автопостинг → «…» → Disable workflow |
| Возобновить | Enable workflow, затем Run workflow |
| Время постов | Settings → Secrets and variables → Actions → **Variables**: `MORNING_TIME`, `EVENING_TIME` (например `07:00`) |
| Другой канал | там же: `TELEGRAM_CHAT_ID` (например `@kanal`) |
| Свежесть новостей | там же: `MAX_AGE_DAYS` (по умолчанию 3) |
| Источники новостей и слова для отбора | файл `config/sources.yaml` |
| Страницы цитат и запрещённые слова | файл `config/quotes.yaml` |
| Опубликовать пост прямо сейчас | Проверка и тестовый пост → `morning`/`evening` без `dry_run` |

## Если что-то не так

| Симптом | Решение |
|---|---|
| В Actions нет идущего запуска «Автопостинг» | Цепочка прервалась: нажмите Run workflow. Запасной запуск по расписанию и так срабатывает раз в 3 часа |
| Красный крестик на «Проверить секреты» | Проверьте секрет `TELEGRAM_BOT_TOKEN` |
| `chat not found` / `not enough rights` | Бот не администратор канала или неверный `TELEGRAM_CHAT_ID` |
| Вечерний пост пропущен | За 3 дня в источниках не было новой новости по темам канала. Можно добавить источники или слова в `config/sources.yaml` |
| Нет новостей ЦБ | cbu.uz закрыт для зарубежных серверов, и из GitHub он не открывается (так же было в uz-business-news) |

## Устройство

| Файл | Что делает |
|---|---|
| `bot/__main__.py` | команды `run`, `post`, `check` и ожидание времени публикации |
| `bot/quotes.py` | цитата дня с Викицитатника |
| `bot/news.py` | сбор источников и выбор новости дня |
| `bot/fetch.py` | скачивание новостей: RSS, HTML, API gov.uz (из uz-business-news) |
| `bot/uzbek.py`, `bot/translate.py` | узбекская версия, перевод и новый алфавит (из uz-business-news) |
| `bot/images.py` | картинка, карточка и водяной знак |
| `bot/format.py` | оформление поста |
| `bot/telegram.py` | отправка в Telegram |
| `bot/state.py` | состояние: что уже вышло (ветка `bot-state`) |
