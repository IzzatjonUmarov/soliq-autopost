# Автопостинг для @Soliqmobilxizmati

Бот сделан по схеме [uz-business-news](https://github.com/IzzatjonUmarov/uz-business-news) и тоже работает в GitHub Actions: бесплатно, круглосуточно, без компьютера.

## Что делает бот

| Время (Ташкент) | Рубрика |
|---|---|
| 07:00 | **Цитата дня** о деньгах и финансах: Баффет, Франклин, Навои, Беруни и другие. Цитата берётся из открытых источников (Wikiquote, сборники цитат), с автором и ссылкой на источник. Бот ничего не сочиняет, а сомнительные цитаты («приписывается») не берёт |
| 18:00 | **Кешбэк, переводы, разбор продуктов**. Перед написанием бот ищет свежие данные на сайтах банков, Click, Payme, Uzum, soliq.uz, kun.uz, gazeta.uz и ставит ссылку на первоисточник |

- **Модель:** `claude-opus-5-5`. Если она откажется писать пост, запрос автоматически уходит на резервную модель.
- **Два языка в одном посте:** сверху русский, ниже узбекский. Узбекский пишется латиницей в новой редакции алфавита по закону ЗРУ-1184 от 21.10.2026: ş, ç, ö, ğ, апостроф ʼ только вместо твёрдого знака.
- **Картинка:** карточка с заголовком в цветах рубрики. На ней плашка @Soliqmobilxizmati в углу и бледный диагональный повтор по всему полю.
- **Точность:** цифры (ставки, % кешбэка, комиссии) бот берёт только из найденных источников. Под вечерним постом стоит «Условия могут меняться».
- **Без повторов:** темы идут по кругу, а бот помнит прошлые посты, поэтому авторы и цитаты не повторяются.
- **Ничего не выдумывается:** если бот не нашёл подтверждённых фактов или цитаты, пост этого слота пропускается.
- **Без дублей и залпов:** после каждого поста состояние сразу сохраняется. Если бот опоздал больше чем на 3 часа, пост этого слота пропускается.

## Настройка (один раз)

1. **Бот Telegram.** Отправьте @BotFather команду `/newbot` и получите токен. Добавьте бота в канал **администратором** с правом «Публикация сообщений».
2. **Ключ Claude API.** Создайте ключ на https://platform.claude.com/ (раздел API Keys) и пополните баланс.
3. **Секреты.** В репозитории откройте Settings → Secrets and variables → Actions → вкладку **Secrets** и создайте:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `ANTHROPIC_API_KEY` — ключ Claude.
4. **Проверка.** Откройте Actions → **Проверка и тестовый пост** → Run workflow → `check`. Должны появиться три зелёные галочки.
5. **Пробный пост.** Тот же запуск, но `morning` или `evening` с отмеченным `dry_run`. Текст будет в логе, а картинка в артефакте `preview` внизу страницы запуска. В канал ничего не уйдёт.
6. **Запуск.** Откройте Actions → **Автопостинг** → Run workflow. Дальше бот работает сам.

## Управление

| Действие | Где |
|---|---|
| Что делает бот сейчас | Actions → последний запуск «Автопостинг» → шаг «Работа бота» |
| Пауза | Actions → Автопостинг → «…» → Disable workflow |
| Возобновить | Enable workflow, затем Run workflow |
| Время постов | Settings → Secrets and variables → Actions → **Variables**: `MORNING_TIME`, `EVENING_TIME` (например `07:00`) |
| Другой канал | там же: `TELEGRAM_CHAT_ID` (например `@kanal`) |
| Другая модель | там же: `AI_MODEL` |
| Темы рубрик | файл `bot/topics.py` |
| Стиль постов | файл `bot/ai.py` (переменная `STYLE`) |
| Опубликовать пост прямо сейчас | Проверка и тестовый пост → `morning`/`evening` без `dry_run` |

## Если что-то не так

| Симптом | Решение |
|---|---|
| В Actions нет идущего запуска «Автопостинг» | Цепочка прервалась: нажмите Run workflow. Запасной запуск по расписанию и так срабатывает раз в 3 часа |
| Красный крестик на «Проверить секреты» | Проверьте секреты `TELEGRAM_BOT_TOKEN` и `ANTHROPIC_API_KEY` |
| `chat not found` / `not enough rights` | Бот не администратор канала или неверный `TELEGRAM_CHAT_ID` |
| Ошибка Claude `credit balance` | Пополните баланс на platform.claude.com |

## Устройство

| Файл | Что делает |
|---|---|
| `bot/__main__.py` | команды `run`, `post`, `check` и ожидание времени публикации |
| `bot/ai.py` | поиск фактов и текст поста (Claude) |
| `bot/topics.py` | темы рубрик |
| `bot/uzbek.py` | перевод узбекского текста в новый алфавит |
| `bot/images.py` | карточка и водяной знак |
| `bot/format.py` | оформление поста |
| `bot/telegram.py` | отправка в Telegram |
| `bot/state.py` | состояние: что вышло и история тем (ветка `bot-state`) |
